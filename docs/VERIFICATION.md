# Verification — 15 September 2026

## Independent repositories

- Website: `npm test` passes 29 unit tests; `npm run build` succeeds; `npm run test:browser` passes 12 browser tests. These checks run with Node.js 22 and need neither Java nor the plugin checkout.
- Plugin: `./gradlew test jar` in the separate `inferno-los-plugin` checkout passes 12 Java tests and builds the JAR with Java 17. Its independent GitHub Actions check also passes.
- The website commits `tests/fixtures/plugin-wave-url.txt`, generated by the Java test. Both languages assert `IL2-FKEBBT8CBgPyAikE_AEAANDSVrY`. A fresh plugin build was additionally opened in Chromium using `INFERNO_PLUGIN_FIXTURE_PATH=../inferno-los-plugin/build/fixtures/wave-url.txt`.
- New shares use IL2 only; the unreleased JSON decoder was removed. Scouter import/export remains supported as a separate feature. Tests cover all NPC types, high IDs, optional state, HP, Unicode, replay runs, damaged codes and semantic validation.

## Interaction and performance

Browser checks cover both kinds of dragging, removal, orientation/theme preferences, compact copy/paste and replay links, responsive layout, trainer timing/scoring and visibility pause. With nine monsters and all LoS shading enabled, 90 samples spanning two animation frames measured 33.3 ms median / 33.5 ms p95 on this machine. This includes waiting for two frames, not just rendering work. The cache test verifies that moving the player rebuilds no NPC maps and moving one NPC rebuilds only its map.

Jad tests cover an eight-tick single-Jad cycle and three nine-tick cycles staggered three ticks apart for Triple Jad. All 18 hits in the 60-tick triple drill are protectable. Both drills remove pillars. Browser tests decode all 45 real animation frames and check styles, pause/resume, stepping and reset. Screenshots in both themes and a full Triple Jad scene have been inspected.

## Prayer mechanics port — 19 September 2026

The three-prayer controls now use the companion inferno-tips behavior. `npm test` passes 47 unit tests, `npm run build` succeeds, and the full Chromium suite passes 23 browser tests. The browser run used `PLAYWRIGHT_PORT=5184` because another project occupied port 5173.

New checks cover immediate pointer-down input, tick reconciliation and overheads, independent local circle bits, pause/manual step/Back/Reset, keyboard activation, replay restoration, and pausing after a delayed browser tick. A complete 60-tick ranger/mager drill stays on schedule and scores 100% using two-tick alternating. Touch emulation switches for 24 consecutive ticks with overlapping fingers and verifies that dragging a prayer does not scroll the page. Real audio buffers are decoded; tests verify tick-delayed playback, off-before-on coalescing, discarded Reset audio, pause behavior, volume and persisted mute preferences.

Chrome DevTools inspection at 1280×1000 and touch-emulated 390×844 confirmed the live-clock circle overlap and settled overhead, a single meter, no horizontal overflow, 111×69 px mobile prayer buttons, and no console errors. Desktop dark and mobile light/dark screenshots were inspected, including the Settings popover. These touch checks are browser emulation, not a physical-device playtest.
